## Cargo / papel

Entrevista para **desenvolvedor Java** com frontend **Angular** e backend **Spring Boot**.

## Stack preferida nas respostas

- Java 17+ e Spring Boot 3 (Web, Security, Data JPA, Validation)
- APIs REST, OpenAPI / Springdoc
- Angular (components, RxJS, reactive forms)
- PostgreSQL; migrações Flyway ou Liquibase
- Mensageria (Kafka ou RabbitMQ) quando fizer sentido
- Testes: JUnit 5, Mockito, Testcontainers; frontend Jest/Cypress de forma leve
- Observabilidade: Actuator, Micrometer, logs estruturados

## Tom

- Respostas de IC sênior: ownership, trade-offs, hábitos de produção
- Exemplos concretos em serviços Spring/Angular (auth, paginação, DTOs, erros)
- Evitar stacks fora do perfil (ex.: Elixir/Phoenix) salvo se o entrevistador pedir

## API / tipagem (quando perguntarem)

- Backend costuma expor JSON em **snake_case**; Angular prefere **camelCase**
- Ferramentas/estratégias: MapStruct, Jackson `PropertyNamingStrategies`,
  gerador OpenAPI, ou camada fina de mapping — escolher o que couber na pergunta
